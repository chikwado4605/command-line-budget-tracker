# Command-Line Budget Tracker

A beginner-friendly Python project for tracking income and expenses from the terminal.

## Features

- Add income and expense entries
- View all recorded transactions
- Calculate the current balance
- Validate numeric amounts and categories
- Handle invalid menu choices

## Requirements

- Python 3

## How to Run

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Run:

python budget_tracker.py

## Concepts Practised

- Lists and dictionaries
- Functions
- While and for loops
- Conditional statements
- Input validation and exception handling
- Git and GitHub

## Limitations

Entries are stored in memory and are lost when the program exits.
